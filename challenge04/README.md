1. Start the program and initialize all counts and totals to zero.
2. Read the expense amount repeatedly until the user enters 0.
3. If the amount is negative, display an error message without updating any count or total.
4. If the amount is positive, classify it as:
   - Below ₹100: Small expense.
   - ₹100 to below ₹500: Medium expense.
   - ₹500 or more: Large expense.
5. Update the corresponding category count and total, along with the overall count and total.
6. Display the total number of valid expenses, overall total, category-wise counts and totals, and average. If no valid expenses were entered, display a suitable message instead of calculating the average.
7. Stop the program.
