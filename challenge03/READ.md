 Algorithm
 Start.
 Read purchase amount.
 Read customer type (1 = Student, 2 = Regular Customer).
 Read delivery distance in kilometres.
 If customer is a student:
   - If purchase amount ≥ ₹2000, discount = 15%.
   - Otherwise, discount = 10%.
 If customer is regular:
   - If purchase amount ≥ ₹3000, discount = 8%.
   - Otherwise, discount = 0%.
 Calculate amount after discount = purchase amount − discount.
 If distance ≤ 5 km, delivery charge = ₹40.
 Else if distance ≤ 15 km, delivery charge = ₹70.
 Otherwise, delivery charge = ₹100.
 Calculate final payable amount = amount after discount + delivery charge.
 Display purchase amount, discount, amount after discount, delivery charge, and final payable amount.
 Stop.
