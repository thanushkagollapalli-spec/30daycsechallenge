2. Read N. If N is than 5 or greater than 12 ask again.

4. Display the readings.
5. Calculate the sum and average of all readings.
6. Find the maximum values using a loop.
7. Find the largest distinct value by checking values smaller than the maximum. If no such value exists, display a message.
8. Count local peaks by checking whether each interior element is greater than both its neighbours.
9. Find the longest strictly increasing run by tracking the current run and the longest run.
10. Read integer K. Normalise it using K % N. If negative, add N.
11. Rotate the array to the right in place using variables and repeated shifts. Do not create another array.
12. Display the array.
13. Calculate R from the two numeric digits of your registration number then calculate D = (R % 9) + 1.
14. Count the values exactly divisible, by D.
15. Display D and the count.
16. Stop.
